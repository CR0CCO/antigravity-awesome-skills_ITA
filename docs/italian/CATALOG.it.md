# Catalogo delle Skill

> **Nota:** Questo catalogo è una versione localizzata dell'intestazione del file principale. Per l'elenco completo e aggiornato delle skill, consulta il file [CATALOG.md](../../CATALOG.md) nella root del repository.

Total skill: 860 (al 2026-02-08)

Le skill sono mantenute in inglese per garantire la compatibilità tecnica con gli agenti AI, ma sono categorizzate qui per una facile consultazione.

## Categorie Principali

- **architecture**: Pattern di architettura, design di sistemi e decision-making tecnico.
- **business**: Strategie di mercato, product management e analisi di business.
- **data-ai**: Intelligenza artificiale, machine learning, ingegneria dei dati e assistenti LLM.
- **development**: Sviluppo software, framework frontend/backend e mobile.
- **general**: Automazione, utility CLI e strumenti di produttività.

Per ogni skill, troverai:
- **Skill**: Il nome dell'identificatore (es. `@brainstorming`).
- **Description**: Una breve spiegazione di cosa fa la skill.
- **Tags/Triggers**: Parole chiave che attivano o descrivono l'ambito della skill.
