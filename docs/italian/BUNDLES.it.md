# 📦 Bundle di Skill Antigravity

> **Collezioni curate di skill organizzate per ruolo e livello di competenza.** Non sai da dove iniziare? Scegli un bundle qui sotto per ottenere un set di skill specifico per il tuo ruolo.

## 🚀 Inizio Rapido

1. **Installa il repository:**
   ```bash
   npx antigravity-awesome-skills
   # oppure clona manualmente
   git clone https://github.com/sickn33/antigravity-awesome-skills.git .agent/skills
   ```

2. **Scegli il tuo bundle** dalla lista qui sotto in base al tuo ruolo o ai tuoi interessi.

3. **Usa le skill** facendovi riferimento nel tuo assistente AI:
   - Claude Code: `>> /nome-skill aiutami a...`
   - Cursor: `@nome-skill nella chat`
   - Gemini CLI: `Usa nome-skill...`
   - Codex CLI: `Usa nome-skill...`

## 📚 Come Usare i Bundle

### 1) Scegli in base all'obiettivo immediato

- Devi rilasciare una funzionalità ora: `Essentials` + un pacchetto di dominio (`Web Wizard`, `Python Pro`, `DevOps & Cloud`).
- Hai bisogno di affidabilità e hardening: aggiungi `QA & Testing` + `Security Developer`.
- Hai bisogno di crescita del prodotto: aggiungi `Startup Founder` o `Marketing & Growth`.

### 2) Inizia con 3-5 skill, non 20

Scegli il set minimo per il tuo traguardo attuale. Espandi solo quando incontri una vera lacuna.

### 3) Invoca le skill in modo coerente

- **Claude Code**: `>> /nome-skill aiutami a...`
- **Cursor**: `@nome-skill` nella chat
- **Gemini CLI**: `Usa nome-skill...`
- **Codex CLI**: `Usa nome-skill...`

### 4) Crea la tua lista personale

Mantieni un piccolo elenco di skill ad alta frequenza e riutilizzalo tra i vari task per ridurre il cambio di contesto.

## 🎓 Percorsi di Apprendimento

### Principiante → Intermedio → Avanzato

**Sviluppo Web:**
1. Inizio: `Essentials` → `Web Wizard`
2. Crescita: `Full-Stack Developer` → `Architecture & Design`
3. Eccellenza: `Observability & Monitoring` → `Security Developer`

**AI/ML:**
1. Inizio: `Essentials` → `Agent Architect`
2. Crescita: `LLM Application Developer` → `Data Engineering`
3. Eccellenza: RAG avanzato e orchestrazione di agenti

**Sicurezza:**
1. Inizio: `Essentials` → `Security Developer`
2. Crescita: `Security Engineer` → Pentesting avanzato
3. Eccellenza: Tattiche dei Red Team e modellazione delle minacce

**Manutenzione Open Source:**
1. Inizio: `Essentials` → `OSS Maintainer`
2. Crescita: `Architecture & Design` → `QA & Testing`
3. Eccellenza: `Skill Author` + workflow di automazione dei rilasci
