# Politica di Sicurezza

## Versioni Supportate

Seguiamo il ramo `main`.

## Segnalare una Vulnerabilità

**NON** aprire una Issue pubblica per exploit di sicurezza.

Se trovi una vulnerabilità di sicurezza (ad esempio, una skill che bypassa il controllo "Solo per Uso Autorizzato" o esegue codice dannoso senza avviso):

1. Email: `security@antigravity.dev` (Segnaposto)
2. Oppure apri una **Private Advisory** su questo repository.

## Politica sulle Skill Offensive

Ti preghiamo di leggere le nostre [Linee Guida sulla Sicurezza](docs/SECURITY_GUARDRAILS.md).
Tutte le skill offensive sono rigorosamente destinate **solo a scopo educativo e professionale autorizzato**.
